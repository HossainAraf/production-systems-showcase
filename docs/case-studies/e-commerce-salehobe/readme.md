# Project name: SALEHOBE

SALEHOBE is a high-performance, full-stack e-commerce platform built with a modern architecture that seamlessly integrates a Next.js 15 frontend and a Rails 8 backend.

    The SALEHOBE-FRONTEND leverages Next.js 15 (App Router) to deliver sub-second homepage rendering times, ensuring a smooth and responsive user experience. Its modular design follows Technical Agile principles, emphasizing performance optimization, scalability, and clean separation of concerns.

    The SALEHOBE-API is a modular, versioned Rails 8 backend powered by PostgreSQL. It embodies Evolutionary Architecture principles with schema-first database design, clean controller inheritance, and planned iteration cycles. This ensures maintainability, adaptability, and robust data handling for future growth.

## Tech stack:
-  API-server: Ruby on Rails
-  Database: PostgreSQL
-  Frontend: Next.js(App Router)
